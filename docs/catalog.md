# Tools, skills, and repository catalog

Only implemented resources are listed below. Future ideas live in the [roadmap](roadmap.md).

| Resource | Format | What it helps with | Requirements |
| --- | --- | --- | --- |
| [Career Studio](../apps/career-studio) | Browser app and source | Edit resume text, reorder sections and entries, review agent changes, draft application materials, export a personal website | Modern browser; a static server for local use |
| [Resume review](../skills/career-resume-review/SKILL.md) | Agent skill | Interview the applicant, identify evidence, and revise a resume without inventing claims | An assistant; optional Codex skill installation |
| [Tailor an application](../prompts/tailor-application.md) | Copy/paste prompt | Map a job brief to confirmed experience and identify gaps | Your resume and a target role |
| [Cover letter](../prompts/cover-letter.md) | Copy/paste prompt | Explain fit with concrete examples and motivation | Confirmed experience and employer context |
| [Initial outreach](../prompts/outreach.md) | Copy/paste prompt | Draft a concise first message with a specific reason and request | Recipient context you can verify |
| [Build your own Career Studio](../apps/career-studio/docs/agent-prompt.md) | Source build prompt | Adapt the editor and website in code | A coding assistant or development environment |

## Repository directory

[zach-hynek/career-consulting](https://github.com/zach-hynek/career-consulting) is the current home for these resources. No separate tool repositories have been spun out yet.

To suggest another repository, include its source URL, license, maintenance status as of a stated date, what it does, and any accounts or paid services it requires. A listing should explain a real use rather than imply an endorsement or a job-placement result. Do not copy another project's source without its license and attribution.
